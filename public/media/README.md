# CHEC media assets

Place approved, licensed brand media in this directory and reference it from the storefront.

Suggested structure:
- `campaign/` — hero, lookbook, monochrome campaign, category photography
- `products/` — isolated product photography, front/back/detail views
- `studio/` — architectural room, mannequin, bag-stage textures
- `models/` — optimized GLB/GLTF models and supporting textures for a future real-time 3D scene

The current storefront uses remote Unsplash editorial imagery and CSS-built architectural scene treatments. No 3D model files are included yet; the CSS scenes are not a substitute for a fully modeled Three.js environment. Replace remote imagery with owned/licensed assets before commercial launch.
